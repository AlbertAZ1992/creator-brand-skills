# Changelog

All notable changes to Creator Brand Skills are documented here.

## 0.1.0 - 2026-08-31

First public toolkit release.

- Ships four independently installable Agent Skills: Logo to Clay, Image to
  Sticker, Feature to Icons, and Product to Mascot.
- Adds one source-to-output ALBERTAZ brand story across all four public
  galleries, while keeping additional technology and fictional-product tests.
- Includes verified OBJ/MTL geometry, transparent RGBA sticker files, editable
  animated SVGs, and five-pose mascot reference sets.
- Adds the focused ALBERTAZ Doodle Icons playground with playback, motion,
  palette, copy, and download controls.
- Verifies Skills CLI discovery, README assets, shell scripts, package tests,
  committed examples, and production deliverables in GitHub Actions.
