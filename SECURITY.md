# Security policy

## Supported versions

Security fixes are applied to the latest state of the `main` branch and the
latest GitHub Release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Include the affected Skill, reproduction steps, impact, and any suggested
   mitigation.

Do not open a public issue for an unpatched vulnerability. You can expect an
initial response within seven days. No bounty program is currently offered.

Generated media quality problems, unsupported source images, and ordinary
validation failures are not security vulnerabilities; please report those with
the bug template.
